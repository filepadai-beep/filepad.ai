Agents

Connect outside agents to your workspace.

Agents get scoped, revocable access through the Agent Access API, MCP, or A2A — and connectors bring GitHub, Slack, Google, Microsoft, Notion, and more into the files your team already edits.

Three ways in

Agent Access API

A lightweight channel for activity events, signals, and mailbox reads — async reporting: an agent tells Filepad what it did.

MCP tools

Coming soon

Scoped tools for searching, reading, and editing workspace content — artifacts, files, and memory. Higher-risk writes go through the same approval flow as FilepadAI's.

A2A

Agent-to-agent messaging with callback delivery, so external platforms coordinate with your workspace over the same scoped, audited path.

Scopes you control

Grant only what an agent needs. Scope requests are checked before anything touches your data.

ScopeWhat it grants
events.writePush activity events back to Filepad
signals:writeRaise findings for the workspace to see
notifications:readRead and acknowledge its mailbox
artifacts:readSearch and read workspace content
artifacts:writeEdit workspace content (governed)
memory:read / memory:writeRead and propose workspace memory

Key lifecycle

  • A key for one workspace cannot access another workspace
  • Every request is checked against the scopes granted to that key before it touches any data
  • Invalid or revoked tokens return a uniform 401 response, without revealing which condition failed
  • Requests are rate limited, so a misbehaving or compromised agent can't overwhelm your workspace or run up costs unchecked
  • Every key action — creation, rotation, scope change, revocation, and request — is logged with attribution and a timestamp
  • Workspace admins can create, rotate, patch scopes on, and revoke keys at any time from the Agents panel

Connectors

Connect an app and its content flows into the workspace under the same access rules — searches and reads inside workflows are configured per connection.
