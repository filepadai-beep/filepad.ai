Filepad Docs

Learn the Filepad workspace model, connect external agents, and build reliable AI-assisted workflows.

Filepad is a file-first workspace for AI-assisted work: real files for instructions, skills, memory, sources, artifacts, and reviewed automations. Everything important stays visible, editable, versioned, and reviewable.

Getting started

  • Quickstart — Create a workspace, connect an agent, and review your first diff.
  • Core concepts — Workspaces, scoping, proposals, skills, memory, and FilepadAI.

Guides

  • Setting up your workspace — Populate the 8 standard folders and get ready for a run.
  • Connecting an agent — Create an Agent Access key, scope it, and run your first job.
  • Reviewing diffs and approvals — How the proposal model works and how to review effectively.
  • Writing effective skills — Reusable prompt modules your agents discover and call.

Agent Access

  • Agent Access overview — Connect external agents with scoped HMAC keys.
  • Agent Access API v1 — Read files, discover skills, write artifacts, and report activity.
