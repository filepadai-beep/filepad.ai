Filepad Docs

Learn the Filepad workspace model, connect external agents, and build reliable AI-assisted workflows.

Filepad is a file-first workspace for AI-assisted work: real, versioned documents; a native assistant that edits them in the open; and governed writes so higher-risk changes wait for your approval. Everything important stays visible, editable, and reviewable.
